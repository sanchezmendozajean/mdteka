# 11 · Atajos de teclado

En macOS, `Ctrl` = `Cmd`. Todos son reasignables en Ajustes › Atajos.

| Acción | Atajo |
|--------|-------|
| Nuevo documento | `Ctrl+N` |
| Nuevo proyecto | `Ctrl+Shift+N` |
| Abrir | `Ctrl+O` |
| Guardar / Guardar como | `Ctrl+S` / `Ctrl+Shift+S` |
| Cerrar pestaña | `Ctrl+W` |
| Siguiente / anterior pestaña | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Imprimir | `Ctrl+P` |
| Exportar PDF | `Ctrl+Shift+E` |
| Deshacer / Rehacer | `Ctrl+Z` / `Ctrl+Y` (`Ctrl+Shift+Z`) |
| Negrita / Cursiva / Tachado | `Ctrl+B` (en editor) / `Ctrl+I` / `Ctrl+Shift+X` |
| Código en línea | `Ctrl+E` |
| Enlace | `Ctrl+K` |
| Normal / Título 1–6 | `Ctrl+0` / `Ctrl+1`…`Ctrl+6` |
| Lista viñetas / numerada / tareas | `Ctrl+Shift+8` / `Ctrl+Shift+7` / `Ctrl+Shift+9` |
| Cita | `Ctrl+Alt+Q` |
| Símbolo (selector: «, », —, –, …; se elige con 1–9, flechas o Enter) | `Ctrl+Shift+.` |
| Bloque de código | `Ctrl+Alt+C` |
| Salto de página | `Ctrl+Enter` |
| Pegar sin formato | `Ctrl+Shift+V` |
| Pegar como Markdown (interpreta la sintaxis, solo WYSIWYG) | `Ctrl+Alt+V` |
| Buscar / Reemplazar | `Ctrl+F` / `Ctrl+H` |
| Buscar en proyecto | `Ctrl+Shift+F` |
| Ir a archivo del proyecto (selector rápido) | `Ctrl+Shift+O` |
| Paleta de comandos | `Ctrl+Shift+P` |
| Alternar WYSIWYG / Texto | `Ctrl+/` |
| Alternar Páginas / Continua | `Ctrl+Alt+P` |
| Mostrar/ocultar navegador | `Ctrl+Shift+B` |
| Mostrar/ocultar panel Documento | `Ctrl+Shift+D` |
| Colapsar cinta | `Ctrl+F1` |
| Concentración | `F11` |
| Zoom + / − / 100 % | `Ctrl+=` / `Ctrl+-` / `Ctrl+Alt+0` (`Ctrl+0` queda para el estilo Normal) |
| KeyTips de la cinta | `Alt` |

> Nota: en el editor, `Ctrl+B` es negrita; el navegador se alterna con `Ctrl+Shift+B` para no chocar.

La **paleta de comandos** lista todos los comandos con su ícono y atajo.
